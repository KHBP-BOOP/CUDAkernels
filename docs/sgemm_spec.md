# FP32通用矩阵乘法算子


## 第一版算子

### 语义

设有：

$A \in \mathbb{R}^{M \times K}$  
$B \in \mathbb{R}^{K \times N}$  
$C \in \mathbb{R}^{M \times N}$

则该算子：

接收两个矩阵，输出一个矩阵即前两者矩阵乘法的结果。该语义是BLAS意义上的简化版  
> 对应torch.mm(A, B)，该函数只能接收两个2D张量，输出一个2D张量作为结果。不执行batch broadcasting

## 输入输出

| 项目 | 说明 |
| :--- | :--- |
| 输入 A | 2D CUDA Tensor, `torch.float32`, 形状 `[M, K]` |
| 输入 B | 2D CUDA Tensor, `torch.float32`, 形状 `[K, N]` |
| M、N、K取值 | 均大于 1 |
| 数学计算 | $C = AB$ |
| 输入修改 | 不修改 A、B，不原地覆盖输入 |
| 输出 C | 新分配的 CUDA Tensor, `torch.float32`, 形状 `[M, N]` |
| 设备要求 | A 和 B 位于同一个 CUDA 设备 |
| 内存布局 | 输入只支持连续存储的2D张量 |
| 转置、广播 | 不支持 |

## 异常行为

1. 输入不是2D Tensor，应当报错  
2. A、B 的内部维度不匹配，应当报错  
3. dtype 不符合要求，应当报错  
4. 两个输入不在同一 CUDA 设备上，应当报错

## FP32数值精度详情

| 项目 | 说明 |
| :--- | :--- |
| 输入类型 | FP32 |
| 输出类型 | FP32 |
| 累加类型 | FP32 |
| 基础计算路径 | 以 FP32 计算 |
| 数值验证基准 | 以 FP32 验证 |
| 比较方式 | 使用绝对误差和相对误差，不要求逐位完全相同 |
